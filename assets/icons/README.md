# Icons

## Generated

Every `.svg` here is written by `scripts/generate_icons.py` and is checked for
freshness by the tests. Do not edit them by hand.

- **Technology tiles** (`python.svg`, `rust.svg`, and so on) draw the marks
  vendored in [scripts/data/icons.json](../../scripts/data/README.md), from
  Simple Icons (CC0 1.0).
- **Link buttons** (`btn-*.svg`). The npm button uses the vendored npm mark. The
  globe, the page, and the `in` tile are simple shapes drawn in the generator;
  the `in` tile stands for LinkedIn without reproducing its logo.

The marks are trademarks of their owners and only name technologies and
services the profile's text already mentions.
